# CMS Gaps in Care Dashboard (De-Identified)  
## Automating Clinical Performance Reporting for ACOs  

***

### Project Overview
In 2019, I partnered with a clinician to automate a highly manual reporting process used to track CMS Gaps in Care and CMS Measures Performance
for an Accountable Care Organization (ACO). Every mid-year, hundreds of Excel files were manually consolidated by copying and pasting data into
a single workbook, a process that often took several weeks.

The goal was to create a centralized, interactive dashboard that allowed clinicians to easily identify:

- Measures Performance
- Providers needing improvement
- Progress toward year-end quality goals

This prototype not only streamlined internal reporting but was later adopted into our company's production
analytics platform, "Optimize", was deployed within five months.

***

### Problem Statement

| Challenges | Descriptions |
| :--- | :--- |
| Manual Consolidation | Hundreds of XLS files were merged manually every reporting cycle |
| Time Intensive | The Process took several weeks to complete |
| Static Insights | Clinicians relied on filters and pivot tables with limited interactivity |
| Delayed Action | Leadership lacked timely insights into Measure Performance |

***

### Solution

- Conducted stakeholder interviews to identify the key metrics most important for the client.
- Built an interactive Excel dashboard that automatically aggregated all the data sources.
- Designed visuals and filters for:
  - Provider-level performance
  - Measures-level trends
  - Gaps in care across different specialties
- Iterated over three weeks based on clinical feedback to refine layout and usability.
- Prototype was integrated into the company's analytics platform, Optimize,  to connect directly to
  warehouse data.

***

### Results & Impact
- Reduced reporting time from 3 weeks -> under 2 days
- Improved real-time visibility into Measures Performance
- Streamlined ACO reporting workflow across multiple teams
- Adopted into the production analytics platform within 5 months

### Data Privacy Notice
This project contains fully de-identified sample data to comply with HIPAA regulations.
All personally identifiable information (PII) and protected health information (PHI) have been removed or 
replaced with randomized placeholders.
The logic, structure, and visual design accurately reflect the original implementation while preserving privacy
and ethical standards.
